# M2 short rehearsal questions

**What does Routing OFF change?** It turns off only the tool-routing flag inside the same frozen integrated agent. The primary generator is Random. Planning, memory, reflection and exploration remain enabled; this is different from the standalone Random baseline.

**Why is Full EF versus Random 9.29 when the mSUN means are 10 and 4.06?** EF is calculated for each matched discovery history and then aggregated. It is not the ratio of grand mSUN means. The official calculation retains a small denominator and cap 100 for zero baselines. AF also uses the official baseline-target/reachability convention. Neither describes machine speed.

**Can the M3 gains be compared directly with Full?** M3's study keeps exploration and routing OFF throughout, so each component effect is paired with `m3_full`. All-enabled Full is a different setting. Additional Full planning/self-correction experiments are a scope decision for M1/M6.

**Did exploration help?** Full minus Exploration OFF is +0.3333 mSUN and −0.1111 AUDC on this dev sample, with mixed pairs. Lower pooled dispersion across systems is descriptive. It does not prove a causal reliability improvement or statistical significance. The Ga–Pt–Tm17 log contains eight mixed and twelve exploit steps; only query6 is ternary, so six alleged ternary probes must not be used as an explanation.

**Are the curves original checkpoint histories?** Their provenance differs by source. Some histories were retained, while M1/M3/M5 supplied trajectory reconstructions and M2 routing uses separately validated record-only reevaluation. Originals and incomplete captures remain preserved. M5's incorrect supplementary normalized field is corrected only in separate views; primary metrics are unchanged.

**Why not claim the project is completely finished?** The assigned dev packages and current analysis are complete. M6's remaining Full/Chemeleon check and course hidden comparison, final group report/deck, rehearsal and submission are still separate tasks. The current results cannot support a held-out generalization claim.
