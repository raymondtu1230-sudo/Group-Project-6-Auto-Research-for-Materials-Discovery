# Speaker notes for the two-slide method draft

## Slide 1, approximately 45 seconds

My component separates an evidence log from the memory presented to the Planner. The evidence log preserves the public results of evaluated candidate structures. The adapter returns a small list of recent observations and contrasting outcomes, keeping the context bounded. Chemical composition alone does not identify a structure, so separate attempts retain separate records. The core also supports composition-targeted retrieval, but that option is not active through the current M1 hook. The Planner still needs to consume the memory before we can evaluate its effect.

## Slide 2, approximately 45 seconds

The current evidence establishes that the workflow runs and the final query is retained. One real Mg-Sn-Sr episode completed all 20 campaign queries in about two minutes and 37 seconds. Initialization also evaluates reference structures, so 20 is not the total oracle workload. The next experiment will compare the frozen full agent with memory disabled under matched settings. We have not measured a memory benefit yet. After those runs, the final slides will add the comparison and two or three traceable discovery cases.
