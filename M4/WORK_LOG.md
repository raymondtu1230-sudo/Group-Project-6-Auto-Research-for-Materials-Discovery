## Technical lessons supported by the evidence

- Newly discovered observations can still be unstable. The observed stability and novelty flags must remain separate.
- Online memory hooks can omit the final observation, so the full official trajectory is the authoritative complete run record.
- Memory has mixed pairwise effects. A favourable aggregate difference does not establish uniform improvement or explain the causal effect of a particular unrecorded memory ID.
- Runtime comparisons across different machines do not isolate Memory overhead. Campaign budgets exclude uninstrumented initialization work, and missing usage counters remain missing.
- Configuration-construction tests need Hydra's runtime context even when scientific episodes run correctly.
